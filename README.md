# Watchlist

Watchlist allows a user to track their favorite TV shows and movies and rank them.

## Features

- Rank TV shows/movies in an ordered list
- Store your current season and episode numbers to keep track of where you are in the show
- Queue your upcoming watches
- Rearrange your rankings as you watch

## Technologies Used

- Swift/SwiftUI
- Loca JSON file storage

## Why I made Watchlist

I developed this app to gain a deeper understanding of application development, data storage, search engines, and application design while searching for a software development position. My goal was to create a tool that I found both useful and engaging, and one that would motivate me to continue pursuing my interests. In the past, I have interned as a software engineer, but my role primarily involved testing rather than development. This experience definitely provided me with a new understanding of application design and an excitement in the fact I was able to create something I am proud of.
